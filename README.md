Interface moderna para análise financeira com foco em usabilidade, clareza e feedback visual.

## ✨ Destaques

- **Dashboard completo** com métricas, gráficos (donut) e saúde financeira.
- **Simuladores de cenário** ("what if") e projeção de poupança.
- **Histórico de análises** com comparação por período.
- **Componentes reutilizáveis** e layout responsivo.

## 🧩 Estrutura

```
src/
  components/      # Dashboard, AnalysisForm, gráficos e simuladores
  services/        # api.ts, auth.ts
  lib/             # utils.ts
  app.css
  App.tsx
  main.tsx
```

## ▶️ Como rodar

```bash
npm install
npm run dev
```

O app estará disponível em `http://localhost:5173`.
